# Student Database System

## Description
Student Database System is a DOS-based application developed in 8086 Assembly Language. The system allows users to add, search, delete, and display student records through a menu-driven interface.

This project demonstrates fundamental Assembly Language concepts such as arrays, procedures, loops, conditional statements, and DOS interrupt `21h` for input/output operations.

---

## Features
- Add Student Record
- Search Student by Roll Number
- Delete Student Record
- Display All Students
- Input Validation for Semester and CGPA
- Menu-Driven Console Interface

---

## Technologies Used
- 8086 Assembly Language
- DOS Interrupt `21h`
- EMU8086 / DOSBox

---

## Student Record Fields
Each student record contains:
- Roll Number
- Name
- Semester
- CGPA

---

## How to Run
1. Open the project in EMU8086 or DOSBox.
2. Assemble and compile the code.
3. Run the executable file.
4. Select options from the menu to manage student records.

---

## Learning Outcomes
This project helps in understanding:
- Low-level programming
- Memory management
- Array handling
- Procedures and loops
- DOS interrupt handling
- Data storage techniques in Assembly Language
